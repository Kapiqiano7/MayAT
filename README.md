# Monika, are you Alan Turing? (MayAT)

An unofficial fan-made dialogue submod for **Monika After Story (MAS)**.

**MayAT** is a technology- and computer-science-themed dialogue project. The idea is to give Monika room to talk about much more than one operating system: Linux is where the project began, not where it has to end.

## 🧠 First Collection: Linux Distributions

The first five conversations explore popular Linux distributions, their features, philosophies, package managers, and differences.

- **Ubuntu** – A user-friendly Linux distribution based on Debian.
- **Arch Linux** – A lightweight, highly customizable rolling-release distribution.
- **Fedora** – A modern distribution focused on new technologies.
- **Linux Mint** – A comfortable and beginner-friendly desktop distribution.
- **Debian** – A community-driven distribution known for stability.

## 💡 A Broader Technology Project

Future conversations can explore different areas of technology and computing, for example:

- Operating systems beyond Linux.
- Computer hardware and architecture.
- Programming languages and software development.
- The internet, networking, and digital infrastructure.
- Computer history and technological milestones.
- AI, software, and the way technology shapes everyday life.

These are possible directions for future dialogue collections, not features already included in the current release.

## ✨ Features

- 5 individual Linux dialogue topics in the first collection.
- All conversations are written in English.
- Separate files for each topic.
- Easy-to-edit project structure.
- Designed for Monika After Story.

## 📥 Installation

1. Download the ZIP file attached to the latest release from the **Releases** page. Do not download the automatically generated **Source code** archive. Alternatively, clone the repository using Git.
2. If you downloaded the ZIP file, extract it.
3. Copy the `game` folder into your Monika After Story main directory. If prompted, allow your operating system to merge the folders.
4. Launch Monika After Story.
5. Find the new technology-related conversations under **Talk** → **Hey, Monika...** → **Technology**.
